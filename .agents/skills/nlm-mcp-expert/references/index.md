# Mục lục tài liệu notebooklm-mcp-cli

Thư mục `concepts/` chứa các tài liệu cốt lõi về cài đặt, sử dụng CLI và MCP Server của `notebooklm-mcp-cli`. Tùy theo câu hỏi của người dùng, hãy chọn file phù hợp để đọc chi tiết:

## Các tài liệu có sẵn

1. **`readme_overview.md`**: Tổng quan về dự án, hướng dẫn cài đặt nhanh, liệt kê tính năng chung, xác thực cơ bản, và cấu hình IDE (Claude, Cursor, Gemini). Đọc file này khi cần nắm bức tranh toàn cảnh hoặc cài đặt ban đầu.
2. **`mcp_guide.md`**: Hướng dẫn chi tiết toàn bộ 35+ công cụ MCP (MCP Tools Reference) bao gồm tham số cho Notebooks, Sources, Querying, Studio Content, v.v. Đọc file này khi cần biết cách truyền tham số cho các tool MCP hoặc thiết kế prompt gọi tool.
3. **`cli_guide.md`**: Hướng dẫn toàn diện cách sử dụng dòng lệnh `nlm`. Đọc file này khi người dùng muốn sử dụng qua Terminal/Command Line thay vì qua MCP.
4. **`api_reference.md`**: Tài liệu kỹ thuật sâu về API nội bộ. Đọc file này khi người dùng muốn lập trình tích hợp sâu bằng Python hoặc tìm hiểu kiến trúc nội bộ.
