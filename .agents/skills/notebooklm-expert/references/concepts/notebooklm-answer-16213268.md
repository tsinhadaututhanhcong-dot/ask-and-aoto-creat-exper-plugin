# Upgrade NotebookLM

You can upgrade NotebookLM to get additional capabilities, including higher limits and more  features through [Google AI Plans](https://one.google.com/about/ai-premium/), [Google Cloud](https://cloud.google.com/resources/notebooklm-enterprise?sjid=4840678451071865222-NC&hl=en) , or a qualifying [Google Workspace plan](https://support.google.com/notebooklm/answer/16337734).

## Upgrading via Google Cloud

|  |  |
| --- | --- |
|  | **NotebookLM for enterprise through Google Cloud** |
| **User requirements** | |
| **Plan or license requirement** | You can use NotebookLM if your Cloud administrator has given you access to the following plan:   * NotebookLM for Enterprise * Gemini Enterprise Standard * Gemini Enterprise Plus * Gemini Enterprise Frontline  [Learn about NotebookLM for enterprise](https://cloud.google.com/resources/notebooklm-enterprise). |
| **Features & availability** | |
| **Higher Limits** | 5X or more notebook artifacts, including Audio Overviews, Video Overviews, Reports, and more. Sharing a notebook does not change limits for any collaborator. |
| **Premium features** | Advanced Sharing  Additional privacy and security features like VPC-SC, IAM controls, and enterprise-grade data protection. |
| **Supported countries & languages** | NotebookLM is available in browser to all users above the age of consent (or [applicable in your country](https://support.google.com/accounts/answer/1350409?sjid=12486508145488360696-NA)) in [supported countries & territories](/notebooklm/answer/16164461#notebooklmcountries). | **Applicable Terms of Service** | [Google Cloud Platform/ SecOps Terms of Service](https://cloud.google.com/terms) |
| **Data protections & how your data may be used** | **Enterprise grade data protection:** Our [Privacy Policy](https://cloud.google.com/terms/cloud-privacy-notice) describes how Google Cloud handles your data when you interact with NotebookLM. Your uploaded files will remain within your GCP project. Data regionalization is honored.  Additionally all files, chats and model outputs won’t be reviewed by human reviewers or used to improve generative AI models. |
