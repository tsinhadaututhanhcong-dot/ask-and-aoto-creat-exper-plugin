# Change mode in NotebookLM

To customize your NotebookLM experience, you can switch between:

* Dark mode
* Light mode
* Device mode

**Important:**

* By default, NotebookLM is in Device mode ![](//storage.googleapis.com/support-kms-prod/1KiwDJa0r0goRIkyBOcc3J0lgJ6z9Eb09yaF).
* In Device mode, the color scheme for NotebookLM matches the color scheme of the device you’re on.

1. On your computer, open [NotebookLM](http://notebooklm.google.com).
2. Select Settings ![Settings](//lh3.googleusercontent.com/DCTWxR8NSpeLAuJjoFNQOxeQ81rPk41gYBMaTf8KFIO3vfusid4C-TW6x8GNdXJjt-U=w36-h36) ![and then](//lh7-rt.googleusercontent.com/docsz/AD_4nXdRyBbNaOdqgeDPnH2UfxYRzt3uSLSxqij4E_7RwRG4U7TBEiDVF9YXGzvja9M5I0XxpwPtrepb25zCKtU5MZaA4g-dylkUilvLycYChEcsZvJPJOZT_xmuUHwL7HL0Xx1r46QNJw?key=kQCClX5_UIz46BYCbT7Lztn1) Device ![](//storage.googleapis.com/support-kms-prod/1KiwDJa0r0goRIkyBOcc3J0lgJ6z9Eb09yaF).
3. Switch between Light mode ![](//storage.googleapis.com/support-kms-prod/7mm5XNqfON9xV9yOt9bGQxBEsdGZxG5d8Fkp), Dark mode ![](//storage.googleapis.com/support-kms-prod/s6oUqhUBEcw6xUPhpZDXdnN8OGglUTwngQ6T), or Device mode ![](//storage.googleapis.com/support-kms-prod/1KiwDJa0r0goRIkyBOcc3J0lgJ6z9Eb09yaF).
